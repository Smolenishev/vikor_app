Интерактивный веб-калькулятор для обоснованного выбора по методу **VIKOR** (VlseKriterijumska Optimizacija I Kompromisno Resenje) — когда дешёвые варианты срывают сроки, а надёжные стоят дороже.

Версия 2 ориентирована на закупочные задачи: поставщик, подрядчик, перевозчик, оборудование. На выходе — честный рейтинг с проверкой условий компромисса и **готовое обоснование выбора для протокола комиссии**.

Онлайн-версия: [otter-finance.ru/vikor-calculator](https://otter-finance.ru/vikor-calculator/)

## 🧮 Математическая основа

Метод VIKOR определяет компромиссное ранжирование, основанное на близости к идеальному решению. Для каждой альтернативы вычисляются три показателя:

1. **$S_i$ (Групповая полезность):** взвешенная сумма отклонений от идеала.
2. **$R_i$ (Индивидуальный риск):** максимальное взвешенное отклонение по одному критерию («слабое звено»).
3. **$Q_i$ (Индекс компромисса):** итоговый показатель:

$$Q_i = v \cdot \frac{S_i - S^*}{S^- - S^*} + (1 - v) \cdot \frac{R_i - R^*}{R^- - R^*}$$

где $v$ — вес стратегии принятия решений (по умолчанию 0.5 — баланс между групповой полезностью и индивидуальным риском).

**Условия компромисса:**

1. *Приемлемое преимущество:* $Q_2 - Q_1 \ge 1/(m-1)$
2. *Приемлемая устойчивость:* лидер по $Q$ должен быть лидером по $S$ или $R$

Если оба условия выполнены — победитель однозначен; иначе рекомендуется рассматривать множество компромиссных решений (калькулятор честно об этом сообщает).

## 🛠️ Как использовать

1. **Откройте** `vikor_v2.html` в любом современном браузере — сервер не требуется.
2. **Выберите сценарий** (или «Свой вариант») — критерии и веса подставятся готовыми, их можно править.
3. **Заполните альтернативы** (Блок 2): названия поставщиков/подрядчиков и числовые оценки по каждому критерию.
4. **Настройте стратегию** (Блок 3): параметр $v$ при необходимости.
5. **Нажмите «Рассчитать»** — получите рейтинг, график, проверку условий компромисса, анализ чувствительности и кнопку выгрузки обоснования.

> 💡 Чтобы начать с чистого листа — кнопка 🗑️ «Сбросить все данные» в Блоке 2.
